### AI Contribution
- `Game` 加 lazy 解答快取（`ensureSolution()`：第一次需要時呼叫 `Solver::solve(initialBoard, initialParts)` 存起來；`solutionComputed_`/`solutionExists_` 守重算）。`solveAndApply()` 改成共用同一快取，避免按 F 與顯示提示各解一次。
- `Game::setHintsVisible(bool)`（顯示時 lazy 解；無解則維持隱藏）+ `Game::hintCells() const`（回傳「解答占據、但目前盤面仍 EMPTY」的格；用 part shape + 解答 rotate/row/col 算 rotatedCells）。
- Renderer 加 `drawHints`（半透明綠圓角格，畫在 board bg 之後、parts 之前）。
- main loop 加 `idleTimer`：每 frame 累加 `GetFrameTime()`；`placedCnt` 變化（放置/拔除）或勝利即歸零；`idleTimer >= 30s && !won` 才 `setHintsVisible(true)`。`init()` 清快取 + 關提示，`resetToInitial()` 關提示。

### Human Decision / Review
AskUserQuestion 拍板：提示外觀 = 剩餘解答格全畫半透明綠（非依色 tint、非只下一件）；計時 = 有進度（放置/拔除）就重置。

### Details
- 提示格 = 解答的占據格 ∩ 目前還空的格 → 玩家擺對一格，該綠格就消失，視覺回饋自然。
- 解答 lazy 算：只有玩家真的卡 30 秒才付出一次 solve 成本；按 F 也走同一快取。

### Verification / Tests Performed
- `cmake --build cmake-build-debug`：0 warning 0 error，7/7 編連通過。
- Headless（`Game` 不依賴 raylib）：對 Example1–6 `init → setHintsVisible(true) → hintCells()`，**格數 == 各零件占格總和、全部 in-bounds 且為 EMPTY、顯示前為空**，6/6 OK（事後刪 harness）。

### Result
Phase 4 兩個增量代碼全部完成：F 鍵一鍵自動解 + 卡 30 秒浮現半透明綠提示。新增/改 `Game.{h,cpp}`、`ui/Renderer.cpp`、`main.cpp`。Phase 4 全 10% 之程式面就緒，待 GUI 目視驗收後入帳（1% + 2.5% + 2.5%；TA 測資 +2%/+2% 留 demo day）。
