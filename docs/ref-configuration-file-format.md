# 02 遊戲設定檔格式

## 整體格式

遊戲設定檔分成兩個主要區塊：

1. 前半部分：記錄盤面資訊
2. 後半部分：記錄所有零件資訊

## 前半：盤面資訊

檔案開頭會有三個數字：

```txt
C M N
```

含義：

- `C`：顏色數量
- `M`：盤面列數
- `N`：盤面欄數

也就是盤面大小為 `M × N`，共有 `C` 種顏色。

## 每種顏色的盤面需求

對於每一種顏色，依序記錄：

```txt
<M 個數字代表由上而下每一列，該顏色的零件佔據的格子數>
<N 個數字代表由左而右每一欄，該顏色的零件佔據的格子數>
X1 <接下來 X1 列的輸入為該顏色不可動的零件的座標>
<座標，row column，左上為 0 0>
```

此區塊會重複 `C` 次。

### 座標規則

座標使用：

```txt
row column
```

左上角為：

```txt
0 0
```

## 不可擺放格子

在每種顏色區塊之後，會記錄不可擺放零件的位置：

```txt
X2 <接下來 X2 列的輸入為不能放零件的格子的座標>
<座標，row column，左上為 0 0>
```

這些格子在遊戲中不能被任何零件覆蓋。

## 後半：零件資訊

對於每個零件，記錄：

```txt
ColorIndex M2 N2 <顏色的 Index，零件大小 M2*N2>
<01 數字陣列，1 代表零件佔據的格子，0 代表空格>
```

此區塊會重複直到 EOF。

## 顏色 Index

後方範例中假設：

- 綠色是顏色 `0`
- 藍色是顏色 `1`

## 零件形狀表示

零件使用 0/1 矩陣表示：

- `1`：該位置被零件佔據
- `0`：該位置為空，不屬於零件

例如：

```txt
0 2 2
1 1
1 0
```

表示：

- 顏色：0
- 大小：2×2
- 形狀：一個 L 型零件

## 完整格式模板

```txt
C M N <有 C 種顏色的零件，盤子大小為 M*N>

<M 個數字代表由上而下每一列，該顏色的零件佔據的格子數>
<N 個數字代表由左而右每一欄，該顏色的零件佔據的格子數>
X1 <接下來 X1 列的輸入為該顏色不可動的零件的座標>
<座標，row column，左上為 0 0>
本區塊重複 C 次

X2 <接下來 X2 列的輸入為不能放零件的格子的座標>
<座標，row column，左上為 0 0>

ColorIndex M2 N2 <顏色的 Index，零件大小 M2*N2>
<01 數字陣列，1 代表零件佔據的格子，0 代表空格>
本區塊重複直到 EOF
```
