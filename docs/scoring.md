# 03 功能需求與配分

our goal: 拿愈多分愈好（可拿滿，但若很麻煩可放棄個五分）

## 總成績組成

Project 成績為：

```txt
程式實作分數 + 口頭報告分數
```

超過 100 分以 100 分計算。

## 程式實作配分，共 65%

| 項目 | 配分 |
|---|---:|
| 遊戲本體：基本項目 + 遊戲流程，必須拿滿 | 20% |
| 進階功能 | 10% |
| 自動解題 | 10% |
| 關卡設計器 | 10% |
| 圖形介面 | 15% |

注意：讀入檔案的功能必須能在程式執行時輸入檔案路徑並讀取。若不能在執行時選擇不同檔案載入，則不給分。

## 口頭報告配分，共 60%

| 項目 | 配分 |
|---|---:|
| 流暢度 | 15% |
| 對程式的熟悉度 | 15% |
| 如何用 AI 實作程式 | 30% |

## 基本項目，5%

- [ ] 至少實作兩個 class：
  - `Part`：代表每個零件，1%
  - `Board`：代表盤面，1%
- [ ] 能讀入包含單一顏色零件的遊戲設定檔，並正常顯示零件及盤面，2%
- [ ] 能讀取 demo 當天助教提供的測資，可額外加 2%

## 遊戲流程，15%

基本項目 + 遊戲流程的所有分數都必須拿到。

- [ ] 選擇要移動的零件，不論是否已經在盤面上，並能用 `w/a/s/d` 或滑鼠拖移零件在盤面中的位置，5%
- [ ] 移動零件時，按 `r` 旋轉零件，5%
- [ ] 移動零件時，按 `Esc` 將零件拔掉，1%
- [ ] 移動零件時，按 `Enter` 或滑鼠左鍵放置零件，1%
- [ ] 能夠正確判斷遊戲勝利，1.5%
- [ ] 放置零件時，如果格子已放置其他零件，或有不能放置零件的格子，則放置失敗並印出錯誤訊息，1.5%

## 進階功能，10%

- [ ] 能夠重置盤面為一開始讀進來的狀態，1%
- [ ] 遊戲進行中或遊戲結束後，可以直接開啟新遊戲，而不是關掉程式重開，1%
- [ ] 精美的主畫面和關卡選擇介面，可選擇預先設定好的關卡，1%
- [ ] 如果某一列或某一欄填滿的格子數滿足需求或超出需求，能夠在盤面周圍進行提示，1%
- [ ] 在盤面周圍提示每一列和每一欄目前填滿的格子數，1%
- [ ] 旋轉和移動零件時，旋轉和移動的中心不會是空的，1%
- [ ] 能夠讀入包含兩種顏色零件的遊戲設定檔，以不同顏色顯示不同顏色的零件及盤面周圍的數字，並且能正常遊玩，2%
- [ ] 能讀取 demo 當天助教提供的測資，可額外加 2%

## 自動解題，10%

- [ ] 可以自動解題並顯示解答；若有多個解答，顯示其中一個即可，1%
- [ ] 能解開單色測資，可額外加 2%
- [ ] 能解開雙色測資，可額外加 2%
- [ ] 遊玩時，可以依據解答在盤面上顯示提示，例如半透明綠色區塊，提示哪些格子需要擺放零件，2.5%
- [ ] 題目太久沒有解開時，約 30 秒，才能夠顯示提示，2.5%

## 關卡設計器，10%

### 編輯功能，5%

- [ ] 可以改變盤面大小、零件顏色數
- [ ] 可以指定零件顏色、大小、形狀來新增零件，且必須能新增任意形狀的零件
- [ ] 可以在盤面上設定「不可放置零件的格子」
- [ ] 可以在盤面上設定「預先擺上去且不能移動的零件」
- [ ] 可以設定盤面周圍的數字

### 匯出與遊玩

- [ ] 可以將設計好的關卡匯出成遊戲設定檔格式，可顯示成文字或輸出成檔案，2.5%
- [ ] 可以直接遊玩設計好的關卡，2.5%

## 圖形介面，15%

- [ ] 實作 GUI，2.5%
- [ ] 音效，1%
- [ ] 使用圖片或特別材質來顯示零件，1.5%
- [ ] 旋轉零件的動畫，5%
- [ ] 零件可以跟著游標連續地移動，5%
