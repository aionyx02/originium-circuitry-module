明日方舟 終末地 源石電路修復 小遊戲 
本次project 要實作的是一個來自手機遊戲《明日方舟：終末地》中的解謎
遊戲。在原遊戲中，你需要將機器人的零件正確擺放來修復機器人。 
規則： 
該遊戲類似於Nonogram，一開始你會拿到數個有顏色的零件和一個周圍有
不同顏色數字的盤面。目標是把所有零件擺上盤面使得每一列和每一欄中有顏
色的格子數量等於盤面周圍對應顏色的數字。 
我們先以只有一個顏色的關卡來講解規則。例如下方為一個 3 * 3 的盤
面，由上到下每列要填滿的格子數為3、2、1，由左到右每欄要填滿的格子數
為3、2、1。右方有兩個零件，分別是高度2 寬度2 的L 型零件、以及高度1
寬度3 的一字型零件。 
 
選取零件後可以將其擺上盤面，在擺放時不能讓零件彼此重疊，而且不能
超出盤面。

遊戲設定檔格式 
遊戲設定檔分成兩個區塊，前半部份記錄盤面、後半部份記錄所有零件。 
 
前半： 
◼ 
檔案一開頭會有三個數字C、M、N，代表有C 種顏色、盤面為M 列
N 欄。 
◼ 
之後對於每一種顏色，記錄該顏色每列、每欄需要填滿的格子數以及
該顏色不可移動的零件位置。 
◼ 
之後記錄不可擺放零件的位置 
後半： 
◼ 
對於每個零件，記錄它的顏色、大小、形狀 
在後面的範例輸入中，假設綠色是顏色0、藍色是顏色1。 
C M N <有C 種顏色的零件，盤子大小為M*N> 
 
<M 個數字代表由上而下每一列，該顏色的零件佔據的格子數> 
<N 個數字代表由左而右每一欄，該顏色的零件佔據的格子數> 
X1 <接下來X1 列的輸入為該顏色不可動的零件的座標> 
<座標，row column，左上為0 0>

<座標，row column，左上為0 0>
